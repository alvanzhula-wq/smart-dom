# Contributing to smart-dom

Hi! I'm a UI designer and the creator of this project. 

I designed a unique minimalist layout for Home Assistant using pure Bash. I love the terminal aesthetic and wanted to make something light and stylish that works even on low-end hardware.

### ⚠️ I need your help!
Most importantly: **I don't know how to code the logic.** I've built the visual interface, but I need help with the "backend" part:
* Connecting buttons to the Home Assistant API using `curl`.
* Fetching real data (sensors, lights status) to display in the terminal.
* Optimizing the scripts to run smoothly.

If you know Bash and love Home Assistant, please join me! Feel free to open a Pull Request or create an Issue. Let's bring this UI to life together.
